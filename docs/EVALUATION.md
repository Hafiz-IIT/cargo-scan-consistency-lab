# Evaluation

## Research question
How should declared and physical-side evidence be compared before an automated trade system authorizes downstream action?

## Metrics
- Mismatch sensitivity
- False-alarm rate
- Tolerance robustness
- Severity calibration
- Review-trigger rate

## Falsification criteria
- Large weight/category discrepancies are missed.
- Tolerance settings are ignored.
- Detected discrepancies fail to trigger review.
