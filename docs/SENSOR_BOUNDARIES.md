# Physical sensing boundary

The historical EXIM project discussions considered multiple inspection modalities such as X-ray, terahertz, infrared/hyperspectral sensing, RF-related signals, cameras, weight data, RFID/seal state and other non-document evidence.

This public repository intentionally models those as **abstract evidence channels**.

It does not provide:
- radiation exposure prescriptions;
- equipment construction instructions;
- scanner operating parameters;
- shielding calculations;
- customs inspection procedures;
- claims that a particular modality is safe for a particular cargo class.

Any physical inspection deployment would require qualified domain engineers, radiation-safety specialists where applicable, manufacturer specifications, calibration, and regulator approval.
