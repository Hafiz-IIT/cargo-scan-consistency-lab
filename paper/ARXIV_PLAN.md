# arXiv / preprint preparation plan

## Candidate categories
Category selection must be based on the final contribution. Likely areas may include AI, computer vision, or systems, but no category is fixed yet.

## Required before submission
- [ ] Freeze research question and scope
- [ ] Complete synthetic benchmark
- [ ] Add baselines
- [ ] Run repeated experiments where stochasticity exists
- [ ] Add figures/tables generated from committed results
- [ ] Complete related-work search
- [ ] Add limitations/threats to validity
- [ ] Verify no confidential EXIM/business data is included
- [ ] Verify no unsupported hardware or regulatory claim is made
- [ ] Prepare LaTeX source and bibliography
- [ ] Independent proofreading
- [ ] Check arXiv endorsement/category requirements at submission time

## IP boundary
Publish software/evaluation architecture and measured results. Keep private credentials, customer data, proprietary integrations, confidential workflows and any genuinely novel hardware calibration that requires separate IP review.
